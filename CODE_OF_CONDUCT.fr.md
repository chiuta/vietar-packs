# Code de conduite

[English](CODE_OF_CONDUCT.md) · [Română](CODE_OF_CONDUCT.ro.md) · **Français** · [Italiano](CODE_OF_CONDUCT.it.md) · [Español](CODE_OF_CONDUCT.es.md) · [Português](CODE_OF_CONDUCT.pt.md) · [Deutsch](CODE_OF_CONDUCT.de.md) · [Magyar](CODE_OF_CONDUCT.hu.md)

Nous suivons l’esprit du Contributor Covenant 2.1 : soyez respectueux, accueillez les nouveaux venus, présumez la bonne foi et gardez la discussion centrée sur le travail. Le harcèlement, la discrimination et les attaques personnelles ne sont pas tolérés. Les mainteneurs peuvent supprimer les commentaires, tickets et contributions qui enfreignent ces règles. Signalez les problèmes à alexio@trom.tf.
